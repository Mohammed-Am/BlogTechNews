# TechNews

**TechNews** is a blog platform focused on technology news. It allows users to create, update, and delete blog posts. Built using modern web technologies, TechNews aims to deliver a seamless and engaging user experience.

## Project Overview
![TechNews Screenshot](https://github.com/Mohammed-Am/BlogTechNews/raw/main/techblog%20(1).jpg)

## Features

- **Create Blog Posts**: Add new articles to the blog.
- **Update Blog Posts**: Edit existing articles.
- **Delete Blog Posts**: Remove articles from the blog.
- **Responsive Design**: Built with Bootstrap to ensure a great experience on both desktop and mobile devices.

## Technologies Used

- **Bootstrap**: For responsive and stylish design.
- **Node.js**: JavaScript runtime used for server-side logic.
- **MongoDB**: NoSQL database for storing blog posts and user data.
